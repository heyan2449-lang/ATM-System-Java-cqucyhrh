# ATM 客户端与服务器通信系统

这是一个基于 Java Socket 和多线程技术实现的 ATM 客户端与服务器通信程序。本项目实现了自定义的应用层网络协议（遵循 `RFC-20242024` 规范），支持多客户端并发访问、基本的银行业务操作以及本地数据的持久化。

## ✨ 核心特性

* **自定义 TCP 协议：** 基于标准的 Socket 字节流，实现了应用层的命令与状态机解析，具备良好的跨语言/跨平台兼容性。
* **多线程并发支持：** 服务器端采用线程池（`ExecutorService`）机制，为每个接入的客户端分配独立线程，支持多个 ATM 终端同时操作。
* **数据持久化与并发安全：** 用户余额数据定时同步至本地文件 `balances.txt`。采用 `ReentrantLock` 显式锁机制，完美解决多用户并发取款时可能导致的文件读写冲突。
* **状态机校验：** 严格按照 `未认证 -> 待认证 -> 已登录` 的状态机流转，拦截非法越权指令。
